# Инструменты 2ГИС и Яндекса для анализа конкурентов — что уже есть на рынке

> Разведка от 2026-08-06 для питча заказчику: что из готового уже предлагают сами
> картографические платформы, и чем наш модуль анализа конкурентов
> (`CompetitorAnalysisReport`, roadmap-приоритет) отличается / идёт дальше.

## Коротко

У Яндекса есть встроенный инструмент «Конкуренты» в личном кабинете бизнеса — он
решает похожую задачу, но с оговорками (см. ниже). У 2ГИС отдельного инструмента
анализа конкурентов не нашлось — только обычный публичный каталог. Наш модуль
может закрыть то, чего нет ни у одной из платформ по отдельности: анализ по обеим
картам сразу, разбор текста отзывов (не только цифр), и без необходимости отдавать
нам доступ к личному кабинету клиента.

## Яндекс Бизнес — раздел «Конкуренты»

**Что это:** встроенный раздел в личном кабинете Яндекс Бизнеса (не публичный API).
Открывается через Организации → выбор компании → «Конкуренты» в левом меню.

**Как работает:**
- Список конкурентов формируется автоматически — по той же основной категории
  бизнеса, что и у компании.
- Радиус поиска прогрессивный: сначала **1 км**, если конкурентов мало — расширяется
  до 5 км, затем до 10 и 20 км.
- По каждому конкуренту считаются «переходы» (показы/клики на карточку) за
  последнюю неделю — целиком.
- Позиции в списке обновляются раз в неделю (в ночь с воскресенья на понедельник).
- Пользователь может вручную добавить компании в список или убрать те, что не
  считает конкурентами.

**Ограничения для нас:**
- Это не публичный API — данные видны только владельцу конкретного кабинета
  Яндекс Бизнеса, через авторизованный вход. Чтобы получить эти данные для чужого
  клиента, нужен либо официальный партнёрский доступ, либо реверс-инжиниринг
  личного кабинета (тот же путь, что для write-sync — отдельная, более тяжёлая
  задача, требует тестового аккаунта).
- Метрика — только количество «переходов» (по сути кликов), без содержания: не видно,
  чем конкурент лучше или хуже, только что на него чаще/реже кликают.
- Только по Яндексу — не учитывает 2ГИС вообще.

**Что взять на вооружение бесплатно:** сама идея прогрессивного радиуса (1 → 5 → 10 км,
если на 1 км конкурентов мало) — это просто логика поиска, не требует доступа к
чужому кабинету. Наш текущий план фиксирует радиус 1000м для MVP; прогрессивное
расширение — простое улучшение поверх того же публичного поиска, которое уже
используется (никакого нового доступа не нужно).

## 2ГИС — отдельного инструмента анализа конкурентов не нашлось

В открытых источниках нет публичного 2ГИС-инструмента вида «конкуренты рядом» —
ни в личном кабинете бизнеса, ни в открытом API. Есть только обычный публичный
каталог (`dev.2gis.ru`) — рейтинг, количество отзывов, рубрика, часы работы, контакты.
Это ровно то, что мы уже используем.

## Чем наш `CompetitorAnalysisReport` отличается от готового решения Яндекса

| | Яндекс «Конкуренты» | Наш модуль (план) |
|---|---|---|
| Платформы | Только Яндекс | 2ГИС + Яндекс вместе, один отчёт |
| Что сравнивается | Только количество кликов/показов за неделю | Поля карточки (что заполнено/не заполнено), рейтинг и количество отзывов, **содержание** отзывов (AI-анализ текста: что хвалят, на что жалуются) |
| Доступ | Нужен вход в личный кабинет клиента на Яндексе | Работает по публичным данным — клиенту не нужно отдавать доступ к своему аккаунту |
| История | Обновление раз в неделю, без явной истории версий | Сохраняемый отчёт с историей — можно сравнить с прошлым разом |

**Питч-тезис:** у Яндекса уже есть похожий инструмент, но он видит только цифры кликов
и только свою платформу, и требует доступа к личному кабинету клиента. Наш отчёт
объединяет обе карты в одном месте и объясняет **почему** конкурент выигрывает или
проигрывает — читает реальные отзывы, а не просто считает клики — и не требует
от клиента отдавать нам доступ к его аккаунтам на картах.
